## 1. プロジェクト概要
Unity ML-Agents (Release 23) を用いた、パラサウロロフス（大型二足歩行恐竜）の歩行動作獲得プロジェクト。
物理シミュレーションに基づき、生物学的な妥当性（重心、質量分布）を考慮しつつ、カリキュラム学習によって複雑な歩行動作を学習させることを目的とする。

## 2. 環境構成
*   **OS:** Linux (Ubuntu)
*   **Unity Version:** Unity 6 (6000.3.6f1)
*   **ML-Agents:** Release 23 (Python package v1.1.0)
*   **Python:** 3.10.19 (uv環境: `source .venv/bin/activate`)
*   **Dependencies:** PyTorch 2.2.1+cpu (ONNX互換性のため固定), ONNX 1.15.0

## 3. 主要スクリプト構成

### A. エージェント制御 (`Parasaurolophus.cs`)
*   **役割:** 強化学習のメインロジック。
*   **Observation (観測):** 関節の角度・速度、ターゲットとの相対位置、頭の高さ。
*   **Action (行動):** 各関節の `ArticulationBody` の目標角度（Target Angle）を制御。
    *   出力は「初期姿勢からの変化量」として適用。
*   **Reset Logic:**
    *   `TeleportRoot` で位置移動。
    *   `SetJointPositions` で「保存しておいた初期姿勢（生データ）」を強制適用。
    *   `Sleep()` で物理慣性を完全消去。
    *   **重要:** モデルの軸設定（Blender由来の回転）に対応するため、`0` リセットではなく `Initialize` 時に取得した初期値を基準にしている。

### B. 接触・ゴール判定 (`BodyPartContact.cs`)
*   **役割:** 物理的な接触を検知してエージェントに報告する。
*   **判定ロジック:**
    *   `OnCollisionEnter` (Tag: "field"): 転倒判定。部位名を報告。
    *   `OnTriggerEnter` (Tag: "target"): ゴール判定。Targetは `Is Trigger` 設定ですり抜ける仕様。

### C. 統計・デバッグ (`FallStatsLogger.cs`)
*   **役割:** 「どの部位が地面について転んだか」を集計しCSV出力。
*   **機能:** エージェント初期化時に自動的にシーン内から検索される。

### D. 質量配分ツール (Editor拡張) (`MassDistributor.cs`)
*   **役割:** 恐竜の総重量（例: 3000kg）を、各コライダーの体積比率に基づいて自動配分する。
*   **特徴:** 生物学的特徴を反映（Rootは重く、肺のあるSpineや中空のHeadは軽く設定可能）。

## 4. 学習設定 (Reward & Curriculum)

### 報酬設計 (Reward Signals)
1.  **ゴール到達:** +10.0 (Lesson 0では +30.0)。
2.  **前進速度:** ターゲット方向への速度ベクトルに対する報酬。
3.  **生存報酬:** +0.001 / step。
4.  **ペナルティ:**
    *   エネルギーコスト (出力の大きさ + 滑らかさ)。
    *   頭部安定化 (Headの上下振動に対する罰)。
    *   転倒 (-1.0)。
5.  **ボーナス (Lesson 0-1限定):**
    *   **交互運動 (Cross-Stride):** 左右の足が逆位相で動くとプラス。
    *   **接地 (Ground Contact):** 足裏が地面に近いとプラス。

### カリキュラム学習 (Curriculum Learning)
YAMLの `curriculum_level` パラメータで制御。

*   **Lesson 0 (直進・剛体):**
    *   ターゲット：正面固定。
    *   関節：前後(Twist)以外はガチガチに固定。
    *   特例：頭や尻尾が接地しても転倒扱いしない（這いずりOK）。
    *   目的：とにかく前に進むことを覚える。
*   **Lesson 1 (頭部安定):**
    *   頭の揺れに対するペナルティ強化。
    *   ターゲット：正面固定。
*   **Lesson 2 (旋回解禁):**
    *   ターゲット：360度ランダム配置。
    *   関節：本来の柔軟さに戻す。
    *   ゴール後：エピソード終了せず、次のターゲットが出現（連続タスク）。
*   **Lesson 3 (速度調整):**
    *   指定速度（例: 2.0m/s）を守る報酬を追加。
*   **Lesson 4 (最終到達点):**
    *   すべての規定報酬を有効化。

## 6. 注意事項 (トラブルシューティング)
*   **爆発する:** Physics設定の `Solver Iterations` が低い可能性があります。
*   **リセット時に荒ぶる:** `SetJointPositions(0)` は禁止。必ず `initialJointPositions` を使うこと。
*   **動かない:** Lesson 0 のエネルギーコストが高すぎるか、初期の報酬が少なすぎる可能性があります（現在はLesson 0でコスト無視設定済み）。
